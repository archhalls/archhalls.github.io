# Сайт «Залы мира 2025»

Готовый к заливке каталог. Работает без пересборки: данные — в CSV, фото — в папках.

Сайт размещён:
- **GitHub Pages** (основной): https://archhalls.github.io/

## Структура

```
Сайт/
├── index.html      ← страница каталога (главная)
├── catalog.js      ← скрипт: читает CSV и строит каталог
├── halls-2025.csv  ← данные (источник правды)
└── photos/
    └── <папка зала>/
        ├── 01.jpg
        └── 02.jpg
```

## Как добавить фото

Для каждого зала создай папку с «слагом» (название без спецсимволов, латиницей) и положи туда файлы `01.jpg`, `02.jpg`, … `06.jpg`:

```
photos/
├── twyford-theatre/01.jpg
├── the-pinnacle/01.jpg
└── sirius-glavnyj-zal/01.jpg
```

Скрипт сам превращает название зала в слаг и ищет папку. Показываются только те фото, которые реально существуют.

**Альтернатива (точный контроль):** добавь в CSV колонку `Фото` и укажи пути вручную:
```
Название зала;…;Фото
Twyford Theatre;…;photos/twyford-theatre/01.jpg,photos/twyford-theatre/02.jpg
```

## Как обновлять

- Добавил зал → допиши строку в `halls-2025.csv`.
- Добавил фото → положи файл в папку зала.
- Ничего пересобирать не нужно.

Чтобы обновить, запусти скрипт из папки `Сайт`:

```
python sync_github.py   # обновляет GitHub Pages (git push)
```

### sync_github.py (GitHub Pages)
- Пересобирает `photos.json`, делает коммит и пушит в GitHub.
- Токен доступа лежит в `github_token.txt` (в `.gitignore`, на GitHub не попадает).
- Адрес: https://archhalls.github.io/

## Как проверить локально

Открой `index.html` через локальный HTTP-сервер (не через двойной клик — браузер блокирует чтение CSV с `file://`):

```
python3 -m http.server 8000
```
и открой http://localhost:8000
